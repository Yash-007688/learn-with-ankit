# Learn with Ankit

> **Master the Universe of Physics with Ankit Yadav Sir**

A modern, high-performance web platform built for learning physics interactively with animated concept breakdowns, curated course roadmaps, and an immersive warm amber theme.

---

## 🌟 Key Features

- **Personalized Hero & Aesthetics**: Custom warm amber/brown visual identity tailored to Ankit Sir's brand.
- **Interactive Course Hub**: Filter and explore 6 comprehensive physics modules (Mechanics, Electromagnetism, Thermodynamics, Optics, Modern Physics, Fluid Dynamics).
- **Modern Authentication Flow**: Supabase-powered OAuth & email credentials sign-up and login with password strength detection.
- **Social & Support Integrations**: Direct access to WhatsApp, YouTube, Instagram, and phone support in the unified footer.
- **Powered by BUILDING_VOID**.

---

## 🛠 Tech Stack

- **Framework**: [Next.js 16 (App Router)](https://nextjs.org/)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React + Custom SVGs
- **Database & Auth**: Supabase

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/Yash-007688/learn-with-ankit.git
cd learn-with-ankit
```

### 2. Install dependencies
```bash
npm install
```

### 3. Setup Environment Variables
Create a `.env.local` file in the root directory:
```env
NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
```

### 4. Run the development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
